# Escape From Duckov Fan Wiki

Unofficial fan wiki for **Escape From Duckov** (Steam app 3167020).

- Primary CTA: interactive **Raid Loadout + Hideout Planner** at `/tools/raid-loadout` (presets, Unknown labels, shareable URL)
- Steam-first facts only — no invented DPS / damage cheat sheets
- Home: Steam hero, scan bullets, trailer embed, screenshot gallery, guide cards
- EN pages: beginner, FAQ, about, privacy
- Optional `NEXT_PUBLIC_GA_ID`; no Adsterra on v1
- Optional GSC verification meta left as a commented placeholder until a token exists

```bash
npm install
npm run build
npm run dev
```

Production host (default): `https://escape-from-duckov-wiki.vercel.app`
